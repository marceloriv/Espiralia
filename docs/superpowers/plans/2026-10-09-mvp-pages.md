# Espiralia MVP Pages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar las vistas y componentes del MVP de Espiralia (Profile Gate, App Layout con Sidebar, Dashboard, Agenda, Planner y To-Do) con persistencia local y estilos oficiales basados en DESIGN.md.

**Architecture:** Aplicación SPA React 19 + TypeScript con Vite, enrutamiento ligero por estado para máxima compatibilidad con GitHub Pages, persistencia local reactiva aislada por perfil, y componentes modulares estilizados con CSS variables conectadas a los tokens de diseño.

**Tech Stack:** React 19, TypeScript, Vite, Vitest, React Testing Library, Lucide React, CSS Modules / CSS tokens nativos.

**Spec:** `docs/superpowers/specs/2026-10-09-mvp-pages-design.md` y `docs/ERS.md`

## Global Constraints

- Colores oficiales: `--color-primary: #8E1EA2`, `--color-primary-active: #C654C3`, `--color-primary-soft: #ED96D7`, `--color-primary-disabled: #FFC0DE`, `--color-canvas: #faf9f5`.
- Tipografía: Titulares display serif, cuerpo y controles en sans-serif legible.
- Cero dependencias de servidor: toda la lógica corre en el navegador del cliente.
- Aislamiento de perfiles: ningún evento, tarea o bloque de planner debe mezclarse entre perfiles locales distintos.
- Tipado TypeScript estricto: cero `any` explícitos o advertencias de compilador.

## Review Focus

1. **Persistencia corrupta o vacía:** Al recargar la página o al no existir perfiles previos, la aplicación debe arrancar limpiamente en el Profile Gate sin lanzar errores de runtime.
2. **Validación de PIN:** Si un perfil tiene PIN, debe bloquear el acceso ante PIN incorrecto y solo ingresar con coincidencia exacta.
3. **Consistencia de datos entre vistas:** Una tarea completada en el Dashboard debe reflejarse como completada inmediatamente al navegar a la vista de To-Do, y viceversa.
4. **Borrado seguro en cascada:** Al eliminar un perfil local, los datos de agenda, planner y tareas pertenecientes a ese perfil deben removerse para evitar datos huérfanos.
5. **Responsividad del Sidebar:** En pantallas pequeñas o móviles, el contenido no debe desbordarse horizontalmente y debe permitir navegación clara.
